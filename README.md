## Operations Research Optimization and Linear Programming
Use Python libraries such as PuLP to build linear programming (LP) and integer programming (IP) models.
Solve problems such as capacity-constrained factory location, production planning and allocation, and transportation route optimization.
Interpret the impact of constraints on business decisions through shadow prices and sensitivity analysis (e.g., what is the marginal value of adding one unit of capacity?).

## Machine Learning and Advanced Forecasting
Time series models: ARIMA and Prophet, used for more accurate demand forecasting.
Machine learning models: XGBoost and random forest, for handling multivariate, nonlinear forecasting scenarios.
Model validation: Backtesting methods to evaluate the historical performance of forecasting models.

## Supply Chain Network Design and Simulation
Supply chain network optimization (facility location, distribution network design).
Monte Carlo simulation: assessing the risk of inventory strategies under uncertain demand.
Digital twin concept: using models to simulate supply chain performance under disruptions.

## Data Storytelling and Business Communication
Translate complex model results into business language and explain them clearly to non-technical management. Propose actionable strategic recommendations based on analytical findings (e.g., adjusting replenishment strategies in a certain region, reallocating supplier share). Use data storytelling to drive decisions rather than letting analysis stop at the report level.
